# Agent icon sources

These marks are packaged only to identify the corresponding third-party session provider. Ownership remains with each respective vendor.

- `codex.svg`: OpenAI Blossom from the [OpenAI brand guidelines](https://openai.com/brand/), cropped from the supplied construction SVG without changing the mark geometry.
- `claude.svg`: Claude symbol from Claude's first-party [`favicon.svg`](https://claude.ai/favicon.svg).
- `grok.svg`: Grok symbol from the first-party [xAI documentation favicon](https://docs.x.ai/_next/static/media/favicon-light.0k~92vpfxw07s.svg).
- `opencode-light.svg` and `opencode-dark.svg`: OpenCode square marks from the project's [official repository](https://github.com/anomalyco/opencode/tree/dev/packages/console/app/src/asset/brand).
